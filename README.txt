SITE STATIQUE D'ATELIER NUMERIQUE (livrable 2)

Contenu :
  index.html, services.html, contact.html   pages du site
  css/style.css                              feuille de style
  img/logo.svg                               logo

A faire :
  1. Copie le dossier sur ta VM (scp, dossier partage, ou decompression d'archive).
  2. Place-le dans un dossier dedie, par exemple /var/www/atelier-numerique.
  3. Dans index.html, remplace [TON NOM] et [DATE] dans le pied de page.
  4. Cree et active l'hote virtuel Apache qui sert ce dossier.
  5. Verifie dans le navigateur que les 3 pages et le style s'affichent.
